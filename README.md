## Project Overview
A responsive e-commerce product listing application developed using React and Vite.

## Technologies
- React.js
- JavaScript
- HTML
- CSS
- Vite
- REST APIs
- React Hooks
- LocalStorage

## Features
- Product listing
- API integration
- Random user assignment
- Product search
- Category filtering
- Price sorting
- Product details modal
- Add to Cart
- Cart count
- Cart persistence using LocalStorage
- Loading and error handling

## APIs
- Products: https://fakestoreapi.com/products
- Users: https://randomuser.me/api/?results=10

## Installation
```bash
npm install
npm run dev
```
